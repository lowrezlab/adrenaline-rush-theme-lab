# Adrenaline Rush · Theme Lab

A sandbox for testing storefront themes for [adrenalinerush.shop](https://adrenalinerush.shop/) using the real catalog. Nothing here touches the live store.

**Live:** https://lowrezlab.github.io/adrenaline-rush-theme-lab/

- 7 themes (current site + 6 new directions), switchable from the left panel
- Home / Category / Product pages, Desktop / Tablet / Mobile previews
- Side-by-side compare, live tweaks (saved in your browser)
- **Export for BigCommerce**: Stencil config values, custom CSS overrides, and install steps

Product images and banner art load from the store's BigCommerce CDN.
